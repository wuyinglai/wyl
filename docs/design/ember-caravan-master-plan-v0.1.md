# 余烬商队 · 设计总纲 v0.1

> 灰潮之后，世界没有死，只是路断了。
> 玩家带着余烬核心，驾驶商队，一趟一趟跑通商路，点亮失联城市。

---

| 名词 | 含义 |
|------|------|
| 灰潮 | 大灾难，切断了城市之间的联系，吞没了部分区域 |

| 大安 | 玩家需要抵达并点亮的第一座城市 |

## 2. 主线结构

### 2.1 开局：灰桥镇发现余烬核心

玩家从灰桥镇启程，发现/继承余烬核心，了解到"世界没有死，只是路断了"。
基础玩法教学：商队装载、地图移动、货物与订单、基础战斗、补给与撤退。

### 2.2 第一目标：把余烬核心送到第一座城市大安

玩家的首要任务是把余烬核心送到大安。
过程中逐步解锁商路、驿站、订单、城市复兴的核心循环。

### 2.3 中期目标：恢复大安周边商路，逐步发现第二城

玩家在大安站稳后，经营大安周边，逐步发现第二座城市的线索与商路节点。

### 2.4 长期目标：点亮九城，恢复九城网络

玩家逐步连通更多城市，每座城市提供不同功能、资源、订单与剧情。
最终恢复九城网络。

### 2.5 真结局目标：启动旧时代终局系统，终结或永久削弱灰潮

在九城网络基本恢复后，玩家获得启动旧时代终局系统的能力，
进入真结局，终结或永久削弱灰潮。

## 3. 地点层级

从最小到最大：

- **村庄**：居民点，提供基础交易与补给
- **小镇**：小型城镇，提供更稳定的补给与少量订单
- **驿站**：商路上的中继点，提供补给、休息、中继订单
- **城市**：完整的大型城市，提供工坊、大量订单、城市复兴功能、剧情节点

## 4. 开发范围原则

| 维度 | 说明 |
|------|------|
| 剧情上 | 九城（长期完整叙事） |
| 玩法第一版 | 三城闭环（先把 3 座城市的完整商路循环打通，验证核心玩法） |
| Demo / 早期范围 | 灰桥镇、第一驿站、大安、大安周边、第一条中程商路、第二座城市传言 |

换句话说：
**先打灰桥镇 → 第一驿站 → 大安 → 大安周边 → 第一条中程商路 → 第二座城市传言，**
**做到能让玩家理解核心循环后，再考虑三城闭环。**

## 5. N3 到 N3.5 结构（开局教学 → 正常循环）

N3 到 N3.5 是从开局教学逐步过渡到正常开放商队循环的阶段。

### N3.1：灰桥镇 → 第一个驿站，固定教学图

- 固定地图路线，用于教学
- 教：移动、补给、货车装载、事件、第一场战斗
- 路线固定，随机度低，确保教学顺畅

### N3.2：第一个驿站 → 第一座城市，半随机教学路线

- 引入部分随机事件
- 教：商路节点、不同货物需求、不同战斗类型
- 抵达并点亮第一座城市大安

### N3.3：第一座城市周边经营

- 教：城市功能、工坊、短途订单、城市恢复/复兴
- 玩家开始理解城市复兴循环
- 需要积累资源、理解订单 → 复兴 → 奖励的闭环

### N3.4：第一座城市开放区域

- 教：自由订单系统、村镇与驿站、旧商队残骸、遗迹、第二座城市传言
- 玩家开始有更多选择与路线探索
- 引入更长的商路概念

### N3.5：第一次正常中程商路

- 约 100 天标准路线
- 3 个左右的中继点
- 正常商队远行体验
- 验证核心循环在非教学环境下可正常运转

## 6. 远期规划（仅列方向，暂不开发）

以下系统仅作为远期方向列出，本条及之后若干条不启动开发：

- **士气**：商队成员的士气系统
- **撤退**：已有部分底层，远期完善撤退代价与策略
- **车队牌**：商队配置/卡牌式车队构筑（概念级，暂不实现）
- **城市受袭**：城市被灰潮中的事件袭击
- **灰潮压力 / 灰潮浓度**：灰潮随时间的动态变化
- **商队账本**：财务与统计系统
- **商队竞争**：其他商队 NPC
- **支线势力**：各大城市之外的其他势力
- **九城网络**：完整九城连通
- **真结局**：启动旧时代终局系统
