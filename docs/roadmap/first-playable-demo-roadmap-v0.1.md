# 《余烬商队》第一版可玩 Demo 开发阶段路线图 v0.1

> 路线优先级调整说明：
> 此前曾准备推进 N3.1a 固定教学图，但在用户确认第一版可玩 Demo 的最终范围后，路线优先级调整为：
>
> 先写入 D0–D14 Demo 总路线 → 再做 D0a 基础框架验收 → 再进入 D1 / D2
>
> 本文档为第一版可玩 Demo 的主开发路线。后续开发全部按本路线推进。

---

## 1. Demo 总目标

第一版可玩 Demo 的范围是：

```text
从灰桥镇出发，到成功点亮第二座城市。
```

包含：

1. 开局新手教程
2. 第一座城市大安点亮
3. 大安周边开放区
4. 信息边界（限制远行方向，引导主线节奏）
5. 商队账本（记录玩家状态与主线进度）
6. 第一批中程商路
7. 第二座城市线索
8. 前往第二座城市
9. 第二座城市点亮

并明确：

```text
这版 Demo 不做完整九城，不做真结局，不做大型城市攻防正式系统。
```

## 2. D0–D14 阶段总览表

| 阶段 | 名称 | 核心目标 | 主要开发内容 | 完成标准 |
| :--: | :-- | :-- | :-- | :-- |
| **D0** | 基础框架整理 | 把当前游戏基础跑通 | 地图、角色、战斗、移动、基础 UI、存档框架 | 能开始一局，能移动，能进入战斗，能保存基础状态 |
| **D1** | 灰桥镇开局 | 建立开局地点和商队出发理由 | 灰桥镇、初始三人、余烬核心、第一笔主线订单 | 玩家知道自己是谁、为什么出发、要把核心送去哪 |
| **D2** | N3.1 固定教学路 | 完成灰桥镇到第一个驿站 | 固定路线、基础移动、补给消耗、货车耐久、第一场战斗、基础事件 | 玩家能完成第一段路并抵达第一个驿站 |
| **D3** | 第一个驿站 | 建立中继点概念 | 驿站 UI、补给、零件、修车、休整、天气提示 | 玩家理解驿站是远行安全点 |
| **D4** | N3.2 点亮大安 | 完成从驿站到第一座城市 | 半随机路线、灰烬风暴预警、余烬核心反应、大安抵达、点亮城市 | 玩家成功点亮第一座城市大安 |
| **D5** | 大安基础功能 | 让第一座城市可用 | 城市交易、基础订单、基础工坊、补给/零件价格、城市状态 | 大安成为玩家第一个稳定据点 |
| **D6** | 大安周边经营 | 建立短途商路循环 | 周边村庄、小镇、短途订单、商路安全度、简单倒卖 | 玩家可以在大安周边赚钱、跑订单、稳定商路 |
| **D7** | 商队生存系统补齐 | 让远行压力成立 | 士气、扎营、撤退、补给归零、货车修理、重伤处理 | 玩家能感到远行压力，但失败不会直接毁档 |
| **D8** | 车队牌与货车战斗 | 强化商队特色 | 车队牌、货车冲撞、车灯照射、车棚加固、货车受击逻辑 | 货车不只是血条，而是战斗资源 |
| **D9** | 商队账本与信息边界 | 防止玩家迷路，同时自然限制远行 | 商队账本、主线提示、机会提示、风险提示、未知路线、远方传言 | 玩家知道下一步可做什么，但不会被硬墙限制 |
| **D10** | N4.0 大安开放区 | 完成复杂新手教程后半段 | 大安周边开放、远方路线线索、旧商队日志、探路订单、商队竞争轻量版 | 玩家能在大安区域自由活动，并逐步获得第二城线索 |
| **D11** | 第一条中程商路 | 让玩家第一次真正远行 | 4 段路线、3 个中继点、中程订单、路线风险、撤退与继续 | 玩家能完成约 100 天级别的中程商路 |
| **D12** | 第二座城市方向 | 从信息边界进入远方探索 | 第二城方向确认、远方驿站/前哨、路线准备、携带余烬核心出发 | 玩家明确知道如何前往第二座城市 |
| **D13** | 第二座城市点亮 | 完成 Demo 主线闭环 | 第二座城市地图、核心激活、城市效果、第二城基础功能 | 玩家成功点亮第二座城市 |
| **D14** | Demo 收口与打磨 | 形成第一版完整可玩 Demo | 新手引导、节奏调整、数值初调、bugfix、存档、UI 提示 | 从开局到第二城点亮可完整游玩 |

## 4. 推荐开发顺序

```text
D0 基础框架验收与缺口补齐
→ D1 灰桥镇开局
→ D2 N3.1 固定教学路
→ D3 第一个驿站
→ D4 点亮大安
→ D5 大安基础功能
→ D6 大安周边经营
→ D7 生存系统补齐
→ D8 车队牌
→ D9 商队账本
→ D10 大安开放区
→ D11 第一条中程商路
→ D12 第二城方向
→ D13 第二城点亮
→ D14 Demo 打磨
```

强调：

```text
每个阶段都必须能单独验收、单独提交、单独试玩。
不要把 D0–D14 合并成一个巨型任务。
```

## 5. 第一版 Demo 不做内容

| 内容 | 处理方式 |
| :-- | :-- |
| 九座城市完整系统 | 只在剧情和账本中提到 |
| 城市受袭正式系统 | 只做传言或预兆 |
| 邪教完整支线 | 只埋传言或小事件 |
| 真结局 | 不做 |
| 派遣商队 | 不做 |
| 完整经济模拟 | 只做轻量价格和订单 |
| 多城市倒退 | 不做 |
| 高阶灰潮 Boss | 不做或只做预告 |
| 完整灰潮浓度系统 | 先做轻量隐藏参数和传言 |

## 6. Demo 核心验收标准

第一版 Demo 完成时，玩家应该能体验到：

1. 我从灰桥镇出发
2. 我知道自己带着余烬核心
3. 我有三名初始队员
4. 我能战斗、赶路、消耗补给、修货车
5. 我能抵达第一个驿站
6. 我能点亮大安
7. 我能在大安周边跑订单赚钱
8. 我能通过商队账本知道下一步方向
9. 我能通过线索找到第二座城市方向
10. 我能完成一次中程远行
11. 我能点亮第二座城市
12. 我点亮城市后，世界有实际变化

---

## 7. 开发原则

1. 先做主线闭环，再加支线
2. 先做能玩，再做丰富
3. 先做两座城市，再谈九城
4. 先做固定路线，再做随机路线
5. 先做轻量账本，再做复杂世界压力
6. 先做城市效果，再做城市攻防
7. 每个阶段都要能试玩
8. 不要一次性开放太多系统
9. 所有系统都必须服务商队远行和点亮城市
10. 如果某个功能不能提升第一版 Demo 体验，先放后面

## 8. 下一步任务建议

```text
下一步不是直接实现 D1–D14。
下一步是：

D0a：当前基础框架验收与 Demo 缺口清单
```

D0a 目标：

- 对照 D0 完成标准检查当前代码
- 确认哪些基础系统已经完成
- 确认哪些基础系统还缺
- 输出 D1/D2 之前必须补齐的 blocker
- 不做大功能开发

然后才进入：

```text
D1：灰桥镇开局
D2：N3.1 固定教学路
```
