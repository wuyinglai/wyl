# 余烬商队 - 阶段 5 回归测试清单

> 本文档用于手动验收阶段 5（补给点卡牌升级/删除）的核心功能。
> 所有测试需在浏览器中手动操作，观察控制台日志验证。

---

## 1. 补给点升级卡牌

- [ ] 移动到补给格，弹出补给菜单
- [ ] 选择"升级卡牌"，显示角色列表
- [ ] 选择护路人，显示可升级卡牌列表
- [ ] 选择"举盾"，弹出确认框："确认升级【举盾】为【举盾+】吗？"
- [ ] 取消，返回补给菜单
- [ ] 确认升级，弹出升级成功，显示"返回补给点"按钮
- [ ] 点击"返回补给点"，仍显示补给菜单（不退出）
- [ ] 控制台输出 `[补给] 升级卡牌: 护路人 举盾 → 举盾+`
- [ ] V 键查看牌组，升级卡显示绿色"举盾+"，无"举盾++"

## 2. 补给点删除卡牌

- [ ] 在补给菜单选择"删除卡牌"
- [ ] 选择护路人，显示所有卡牌列表
- [ ] 选择任意卡，弹出确认框："确认删除【卡名】吗？"
- [ ] 取消，返回该角色牌组列表
- [ ] 再次取消，返回补给菜单
- [ ] 确认删除，弹出删除成功，显示"返回补给点"按钮
- [ ] 点击"返回补给点"，仍显示补给菜单（不退出）
- [ ] 控制台输出 `[牌组] 护路人 删除卡牌：...`

## 3. V 牌组查看 instanceId 区分

- [ ] V 键打开牌组查看
- [ ] 升级一张"举盾"后，查看牌组显示"举盾+"
- [ ] 如果有两张同名卡（如两张"盾击"），每张后显示 `#xxxx` instanceId 后4位
- [ ] 同名单卡只显示卡名，不显示 #xxxx
- [ ] 控制台日志也显示 instanceId 后缀
- [ ] 升级/删除后 V 键查看，instanceId 对应的卡已正确替换/移除

## 4. instanceId 精确操作

- [ ] 升级/删除通过 instanceId 精确定位，不依赖列表序号
- [ ] 控制台无 `[补给] 升级失败: instanceId=... 在deck中未找到` warning
- [ ] 同名多卡升级其中一个，不影响另一张

## 5. 升级卡进入下一场战斗

- [ ] 补给点升级"举盾"为"举盾+"
- [ ] 进入下一场战斗（普通战斗）
- [ ] V 键查看 deck，升级卡"举盾+"存在
- [ ] T 键注入升级卡到手牌
- [ ] 打出"举盾+"，护甲增加 11（基础8+升级3=11）
- [ ] 行动力扣除 1
- [ ] "举盾+"进入弃牌堆
- [ ] 弃牌堆显示"举盾+"（非"举盾++"）

## 6. 删除卡不进入下一场战斗

- [ ] 补给点删除"举盾+"
- [ ] 进入下一场战斗
- [ ] V 键查看 deck，删除的卡不存在
- [ ] drawPile 不包含该 instanceId
- [ ] hand 不包含该 instanceId
- [ ] discardPile 不包含该 instanceId

## 7. 升级卡实际出牌效果

- [ ] 升级"举盾"后，打出"举盾+"
- [ ] 护路人获得护甲 11 点（实测）
- [ ] 护路人被动触发，商队护甲 +2
- [ ] 弃牌堆正确记录"举盾+"

## 8. 补给点菜单操作流

- [ ] 升级成功后"返回补给点"，可继续选择：治疗/修车/升级/删除/离开
- [ ] 删除成功后"返回补给点"，可继续选择
- [ ] 连续升级/删除多张卡（返回菜单→再进入）
- [ ] 选择"离开补给点"，完成补给并关闭菜单

## 9. 升级/删除取消流程

- [ ] 升级：选角色→选卡→点取消→返回补给菜单
- [ ] 删除：选角色→选卡→点取消→返回补给菜单
- [ ] 确认升级后点取消→返回角色可升级列表
- [ ] 确认删除后点取消→返回该角色牌组列表

## 10. 代码实现验证

- [ ] `upgradeCard()` 不修改 id 字段，保留原 id
- [ ] `upgradeCard()` 保留原 instanceId
- [ ] 升级/删除用 `findIndex(c => c.instanceId === card.instanceId)` 定位
- [ ] `showDeckViewer()` 直接使用 `card.name`，不拼接 `+`
- [ ] `showDeleteCardSelectCard()` 直接使用 `card.name`
- [ ] `copyCard()` 生成唯一 instanceId
- [ ] 升级卡删除后 deck.length 正确减少
