# 余烬商队 - 阶段 4 回归测试清单

> 本文档用于手动验收阶段 4（卡牌奖励 + 牌组查看）的核心功能。
> 所有测试需在浏览器中手动操作，观察控制台日志验证。

---

## 1. 主菜单

- [ ] 主菜单正常显示"余烬商队"标题
- [ ] 按 Enter 或点击"开始远征"进入角色选择
- [ ] 控制台输出 `[主菜单] 主菜单场景已加载`

## 2. 角色选择

- [ ] 显示 5 个可选角色
- [ ] 选择 3 个角色后可确认
- [ ] 控制台输出 `[角色选择] 已选择: ...`
- [ ] 进入地图后角色状态正确初始化

## 3. 地图移动

- [ ] WASD / 方向键可移动商队
- [ ] 只能移动到相邻可达格子
- [ ] 移动后 day+1，格子标记已访问
- [ ] 连续移动 20 步无卡顿或崩溃
- [ ] 控制台输出 `[地图V2] 移动到 (x, y)`

## 4. 战斗胜利

- [ ] B 键进入普通战斗
- [ ] Q 键强制胜利
- [ ] 胜利后进入卡牌奖励界面（非 Boss 战）
- [ ] 奖励界面显示 3 张卡牌
- [ ] 按 1/2/3 选择卡牌
- [ ] 选卡后控制台输出 `[奖励] 加入卡牌: ...`
- [ ] 1.5 秒后自动返回地图

## 5. 重伤

- [ ] I 键制造重伤
- [ ] 控制台输出 `[调试I] ...`
- [ ] P 键查看商队状态，显示重伤标记
- [ ] 重伤角色下一场不参战
- [ ] 移动 restNodes 个节点后恢复

## 6. 补给点

- [ ] 移动到补给格弹出补给弹窗
- [ ] 可选择治疗/修理/休整
- [ ] ESC 或选择后关闭弹窗
- [ ] 补给后资源正确更新

## 7. 营地

- [ ] 移动到营地格弹出营地弹窗
- [ ] 可选择休息
- [ ] 休息后重伤角色 restNodes-1
- [ ] ESC 或选择后关闭弹窗

## 8. 卡牌奖励

- [ ] 普通战斗胜利后弹奖励界面
- [ ] 精英战斗胜利后弹奖励界面（E 键进入精英战斗）
- [ ] Boss 战胜利后不弹奖励，显示远征胜利
- [ ] 奖励卡只来自存活角色
- [ ] 3 张卡不重复
- [ ] 选卡后 deck 数量 +1
- [ ] 跳过奖励（按 0 或 S）后 deck 不变
- [ ] 跳过后正确返回地图
- [ ] 快速多次按键不会重复加入卡牌
- [ ] 奖励界面打开时其他键不穿透
- [ ] 奖励界面按 F 键自动选择第1张卡（dev-only）
- [ ] 奖励界面按 J 键无响应（防穿透）

## 9. 牌组查看

- [ ] V 键打开牌组查看界面
- [ ] V 键关闭牌组查看界面
- [ ] ESC 关闭牌组查看界面
- [ ] 打开时其他键不穿透（B/K/M/X/H/U/I/O/P/L/R/Q）
- [ ] 关闭后 B 键可正常进入战斗
- [ ] 快速连续按 V 不叠加多层 UI
- [ ] 关闭时控制台输出 `[牌组查看] 已关闭，UI 对象已销毁`
- [ ] 显示角色 HP、重伤状态、重伤次数、牌组数量
- [ ] 牌组超过 10 张时显示"还有 X 张"
- [ ] 死亡角色显示灰色"死亡"标记
- [ ] 场景切换时牌组查看 UI 不残留
- [ ] 牌组查看打开时按 J/Q/R 无响应

## 10. Boss 胜利

- [ ] X 键进入 Boss 战斗
- [ ] Q 键强制胜利
- [ ] 显示"远征胜利"界面
- [ ] 不弹出卡牌奖励
- [ ] 控制台输出 `[战斗] Boss战胜利，进入远征胜利（不弹卡牌奖励）`
